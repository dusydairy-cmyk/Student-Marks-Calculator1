# Student Marks Calculator

A beginner-friendly student mini project built with HTML, CSS, and JavaScript. Enter a student's name and marks in five subjects to calculate total marks, percentage, grade, and pass/fail status.

## Features

- Student name input
- Marks entry for five subjects
- Input validation (each mark must be between 0 and 100)
- Automatic total and percentage calculation
- Grade calculation
- Pass/fail check (at least 35 marks in every subject)
- Responsive layout for mobile and desktop
- Reset button

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enter the student's name and marks.
4. Click **Calculate Result**.

No installation or server is required.

## Grade Rules

| Condition | Grade |
|---|---|
| Below 35 in any subject | F (Fail) |
| 90% and above | A+ |
| 80%–89.99% | A |
| 70%–79.99% | B |
| 60%–69.99% | C |
| 50%–59.99% | D |
| Below 50%, with all subjects passed | E |

**Note:** These grading rules are example rules for this mini project. Change them in `script.js` to match your institution's grading policy.
